📋 Google Forms / Survey Export

  1. Open your Form → Responses → click Link to Sheets (or Download .csv).
  2. Drop the raw .csv or .xlsx file directly below — no **** tags needed.
  3. Pick your open-ended question as Main Text and age/role/rating columns as metadata.

🟠 Reddit Threads (Apify / Export)

  1. Run an Apify Reddit Scraper or PRAW export and download the dataset as .csv or .xlsx.
  2. Drop the spreadsheet below to launch the 5-row column-mapping preview.
  3. Map body / text as Main Text and select subreddit + type to unlock Specificity χ².

▶️ YouTube Comments (Apify)

  1. Scrape target videos with Apify YouTube Comments Scraper and export as .csv / .xlsx.
  2. Upload directly (up to 15 MB / 15,000 rows processed exclusively in RAM).
  3. Map comment as Main Text, choose Corpus Language + Bigrams, and map channelName as metadata.
